# Glossary

**AMR** — Autonomous Mobile Robot.

**WMS** — Warehouse Management System.

**P2P** — Peer-to-peer communication.

**ROS 2** — Robotics software framework and middleware ecosystem.

**Nav2** — ROS 2 navigation framework.

**Zenoh** — Data communication protocol/middleware usable with ROS 2.

**MAPF** — Multi-Agent Path Finding.

**ETA** — Estimated Time of Arrival.

**Conflict graph** — Local representation of robots whose predicted actions may interfere.

**Space-time reservation** — Reservation of a spatial resource for a time interval.

**Task lease** — Temporary task ownership that expires if the robot stops renewing it.

**TTL** — Time To Live; expiration duration for distributed state.

**Graceful degradation** — Losing higher-level capabilities while retaining lower-level safety/autonomy.

**Edge AI** — AI inference performed close to the robot/data source rather than requiring cloud processing.
